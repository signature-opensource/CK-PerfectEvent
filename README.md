# CK-PerfectEvent

[![nuget](https://img.shields.io/nuget/v/CK.PerfectEvent.svg?label=CK.PerfectEvent)](https://www.nuget.org/packages/CK.PerfectEvent/)
[![Licence](https://img.shields.io/github/license/signature-opensource/CK-PerfectEvent.svg)](LICENSE)

Contains [CK.PerfectEvent](CK.PerfectEvent/README.md): .NET events that support three kinds of
callback - synchronous, sequential asynchronous and parallel asynchronous - plus `Adapt` to expose an
event under a base event type, and bridges that relay, convert or filter an event towards another
sender.
